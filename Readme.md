# Add & Remove Game

A simple interactive web project built using HTML, CSS, and JavaScript. Users can add items to a list, remove them, and track their score.

## Features

- Add items to the list
- Remove individual items
- Automatic score updates
- Reset the game
- Add items using the Enter key
- Responsive layout for mobile and desktop
- Input validation

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server or your browser.
4. Enter an item and click **Add Item**.
5. Use **Remove** to delete an item or **Reset Game** to start over.
